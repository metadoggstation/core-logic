# 🐾 METADOGG STATION
**"Building the Sovereign Sanctuary on the Blockchain."**

私たちは、現実世界の経済的・物理的な「危機（Crisis）」から価値を避難させ、自律的に維持・成長させるためのWeb3インフラを構築するオープンソース・プロジェクトです。

---

### 📡 The Mission
今を生きるサイファーパンク達が提唱した「サンクチュアリ・テクノロジー」の概念を、Play to Development（P2D）の装置として実装します。
私たちは、単なるゲームではなく、リモートワーカーが数分間の介入で現実のスキルを経済圏へと接続し、互いの生存を支え合う「自律的避難所」を創り出します。

### ⛽ Core Concept: The PA (Parking Area) Model
- **Proof of Services (PoS)**: 移動コスト（ガス代）がサービスの信頼を担保する。
- **Autonomous Stations**: 各PAはプレイヤーが開発し、独自の経済ルール（コンビニ/EV充電器）を持つ「避難所」となります。
- **Dynamic On-chain Face**: METADOGGたちの表情（NFT）は、あなたの貢献と実績によってAIが再定義します。
